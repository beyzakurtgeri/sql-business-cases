# SQL Business Cases

Welcome to my SQL portfolio.

This repository contains SQL projects based on real-world business cases.

In each project, I will solve business problems, analyze data, and generate meaningful insights using SQL.

## Goals

- Improve my SQL skills through practical business cases
- Develop my analytical thinking and problem-solving skills

## Tools & Technologies

- SQL Server
- Microsoft Power BI
- DAX

## Projects

### 1. Monthly Sales Trend Analysis

This project analyzes monthly sales and order trends and month-over-month changes using SQL on the Northwind database, with the results visualized in Power BI dashboard.

**Business Focus:**
- Monthly sales performance
- Monthly order performance
- Month-over-month changes
- Sales and order trend analysis

[View Project](monthly-sales-trend-analysis)

### 2. Top Customers Analysis

This project identifies the company's most valuable customers based on total sales using SQL on the Northwind database.

**Business Focus:**
- Customer sales performance
- Order count
- Total sales
- Average order value
- Customer ranking

[View Project](top-customers-analysis)

### 3. Top Products Analysis

This project analyzes product sales performance and identifies the top-selling products using SQL on the Northwind database.

**Business Focus:**
- Product sales performance
- Total sales
- Order count
- Average sales per order
- Product ranking

[View Project](top-products-analysis)
